# Contributing

This playbook improves the way it tells you to improve: from evidence, one box at a time.

## The bar for a change

1. It comes from a run. State the machine class or engagement shape where the current text missed surface, wasted time, or ordered work badly, without naming unpublished targets or flags.
2. It is a checkable rule, not an opinion. "When X, do Y, because Z" merges. "Consider maybe doing Y" does not.
3. It lands in the right file: phase steps in the phase, scoring in the decision layer, technique depth in a module. Cross-references beat duplication.

## What does not merge

- Writeups, flags, credentials, or material from active machines. Retired-machine lessons are welcome as rules with the identifying detail stripped.
- Tool lists without a decision rule for when the tool runs.
- Reordering the phase spine without a case that the current order loses time or surface.

## Authorised use

Everything here is for lab platforms, CTFs, and authorised engagements. Contributions framed for unauthorised targets are not accepted.
