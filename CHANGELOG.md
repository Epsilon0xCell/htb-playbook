# Changelog

## v0.1.0, 2026-11-12

First release.

- The eight-phase spine, one file per phase with entry criteria, ordered steps, exit criteria, and a checklist: setup, external enumeration, per-service enumeration, foothold, internal enumeration, privilege escalation, the AD path, and the writeup and review.
- `decision-layer.md`: the prioritisation formula, the two-signal rabbit-hole rule with per-tier backstops, the reset rule, and the difficulty scaling table that decides how deep each phase goes.
- Four technique modules that run on signal, not as sweeps: web and API depth, pwn and reversing triage, crypto misuse, and multi-host pivoting.
- Templates for the box note and the post-box review, plus a command reference keyed to the phases.
